# data-doc — data documentation, lineage, impact, and portal tips
Run coop data-doc lineage <object> before changing shared tables or measures.
Run coop data-doc build to generate Markdown docs and an offline portal.
Run coop data-doc build --reviews <report.json> to add review findings to docs.
Use coop data-doc check in CI to detect stale documentation.
Run coop data-doc scan to parse SQL and Power BI files into graph.json.
Use /setup-docs to configure coop-data-doc.yml in an interactive wizard.
Use /impact-analysis to inspect lineage before changing shared schemas.
Add --depth 2 to coop data-doc lineage <object> to trace two dependency hops.
Open the generated HTML portal for clickable, collapsible lineage graphs.
Read manifest.json for machine-readable nodes, edges, and trust markers.
Scan SQL and Power BI together to trace lineage across both estates.
Configure table and measure descriptions in coop-data-doc.yml.
Use bronze, silver, and gold folders to expose medallion-layer lineage.
Include TMDL and .bim paths in coop-data-doc.yml to document semantic models.
Set output.dir and output.site_dir in coop-data-doc.yml to choose output folders.
Use /discovery to explore and document an unfamiliar data estate.
