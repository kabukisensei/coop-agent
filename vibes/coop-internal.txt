# coop-internal — power-user discovery tips, crew in-jokes, and classics
# (power-user tips, the crew, then allowed classics: South Park / Star Wars / Monty Python)
Type /copy to copy the last assistant response directly to your clipboard.
Type /start to open the Start Here menu of common tasks.
Run /setup-docs to configure and build data documentation in-agent.
Use /handoff to generate a clean summary before pausing work.
Use /explain for an on-demand breakdown of the current plan.
Run /spec-first to draft a spec before modifying project files.
Use /slice-next to plan the next vertical slice with testable checks.
Use /annotate to apply structured Markdown feedback cleanly.
Run /pr-description to draft a Conventional Commits message from diff.
Run /daily-log to log today's session, or /weekly-log for a roll-up.
Use /impact-analysis to check lineage before altering shared schemas.
Run coop -c from your terminal to resume your last session instantly.
Run coop web to launch the local browser UI with Files panel.
Run coop doctor --fix to diagnose and repair setup issues.
Run coop init --seed-docs to scaffold project config and starter docs.
Type /compact to summarize context when conversations grow long.
Type /tree to explore conversation branches and switch directions.
Type /fork to branch a new session from an earlier turn.
Type /model to switch between configured LLM providers and models.
Run /coop-vibe coop-internal to switch to this internal tip & crew pool.
Run /coop-splash to re-display the startup header and wordmark.
In Coop Web, use the Files panel to inspect project files and attach them.
Use COOP_NO_START_MENU=1 to disable the automatic startup menu.
Run /coop-guardrails to see whether Coop's source and destructive-action protections are active.
Run coop sync to restore the curated extensions, MCP config, vibes, and theme.
Run coop update to update Pi, Coop tools, skills, and prompts.
Ask Coop to remember durable preferences; Hermes memory carries them across sessions.
Ask Coop to search the web or fetch a URL with its read-only web tools.
Ask Coop to search Azure DevOps work items directly with natural language.
Ask Coop to run Tabular Editor BPA; the tabular-editor-bpa skill guides the review.
