# professional — polished, client-safe feature discovery tips & quiet classics
Type /copy to copy the last assistant response directly to your clipboard.
Type /start anytime to open the Start Here menu of common tasks.
Run /setup-docs to launch the in-agent wizard and build lineage docs.
Use /handoff to generate a clean summary of changes and next steps.
Use /explain for an on-demand breakdown of the current plan.
Run /spec-first to draft and align on a concise spec before editing.
Use /slice-next to plan the next vertical slice with testable checks.
Use /annotate to apply structured Markdown review feedback cleanly.
Run /pr-description to draft a Conventional Commits message and PR summary.
Run /daily-log to record session work, or /weekly-log for a roll-up.
Use /impact-analysis to assess upstream and downstream effects before edits.
Run coop -c from your terminal to resume your last session instantly.
Run coop web to launch the browser UI with live chat and file previews.
Run coop doctor --fix to diagnose and repair environment setup issues.
Run coop init --seed-docs to scaffold project config and starter docs.
Type /compact to summarize context when conversations grow long.
Type /tree to explore conversation branches and switch directions.
Type /fork to branch a new session from an earlier turn.
Type /model to switch between configured LLM providers and models.
Run /coop-vibe <set> to switch pools, or /coop-vibe all for client-safe tips.
Run /coop-splash to re-display the startup header and brand banner.
