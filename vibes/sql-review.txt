# sql-review — SQL review commands, standards, and CI workflow tips
Run coop sql-review check . to lint T-SQL against Cooptimize standards.
Add --strict to coop sql-review in CI to block on any rule finding.
Use --write-baseline baseline.json to baseline legacy SQL findings.
Pass --baseline baseline.json to report only newly introduced issues.
Use -- coop-sql-review:ignore <rule_id> inline to suppress a rule.
Run coop sql-review check . --format sarif -o review.sarif for code scanning.
Run coop sql-review check . --format html -o report.html for visual report.
Use --target azure-sql to skip Fabric-DW-specific type restrictions.
Run coop sql-review compare old.json new.json to inspect finding deltas.
Use --save-ignores to interactively save rule suppressions to rules.yml.
Run coop sql-review check . offline; no SQL leaves your machine.
Run coop sql-review check . to flag SELECT * in production queries.
Pass --schema <file> to catch cross-file type and conversion issues.
Run coop sql-review check . to enforce PascalCase aliases in silver and gold outputs.
Run coop sql-review rules to list every rule, severity, and tier.
Run coop sql-review explain <rule-id> to read a rule's rationale and standard.
